# 供应商分析 (Supplier Analyzer)

## 核心能力
调用内置的确定性 Python 脚本，完成以下操作：
- 供应商交货准时率分析（计划交期 vs 实际交期）
- 供应商质量合格率分析（合格数量 vs 总交货数量）
- 供应商综合风险评分（交期风险 + 质量风险 + 依赖度风险）
- 供应商排名与分级
- 多供应商物料对比分析

## 输入
- `extracted_summary.parquet`：来自 data-inspector 的汇总数据（**必需**）
- 数据中需包含供应商相关字段：
  - 必需：物料编码
  - 条件必需（至少一项）：供应商名称、计划交期、实际交期、合格数量、交货总数量

## 输出
- `supplier_report.json`：供应商评估报告

## 执行流程

### 步骤 0：环境验证
- 检查 Python 版本是否为 3.11.14，若不匹配则提示用户安装/切换并终止。
- 检查 `uv` 是否可用，若不可用则提示安装并终止。
- 所有脚本调用均使用 `uv run`。

### 步骤 1：前置条件检查
调用 `precondition_checker.py` 检查：
- 必需文件：`extracted_summary.parquet`
- 字段要求：检查数据中是否包含供应商相关字段

若必需文件缺失，拒绝执行并告知用户获取路径。
若供应商相关字段全部缺失，提示用户：
"原始数据中未检测到供应商相关字段（供应商名称、计划交期、实际交期、合格数量等）。
供应商分析无法执行。如需此分析，请确保原始数据包含供应商维度信息后重试。"

### 步骤 2：供应商交期分析
调用 `supplier_evaluator.py` 的交期分析模块：
- 计算每个供应商的平均交期偏差（实际交期 - 计划交期）
- 计算准时交货率（偏差 ≤ 0 的订单占比）
- 识别交期风险供应商（准时率 < 阈值）

### 步骤 3：供应商质量分析
调用 `supplier_evaluator.py` 的质量分析模块：
- 计算每个供应商的质量合格率（合格数量 / 总交货数量）
- 识别质量风险供应商（合格率 < 阈值）

### 步骤 4：综合风险评估
调用 `supplier_evaluator.py` 的风险评估模块：
- 交期风险评分
- 质量风险评分
- 依赖度风险评分（单一供应商物料占比）
- 综合风险评分与分级（低风险/中风险/高风险）

### 步骤 5：结果反馈
- `supplier_report.json` 路径
- 供应商排名摘要
- 风险供应商清单
- 改进建议

## 注意事项（职责边界）
- 本 Skill 不自行编写任何分析代码，所有处理逻辑由预置脚本确定性执行。
- 若供应商相关字段全部缺失，优雅跳过并告知用户。
- 若部分字段缺失（如仅有供应商名称但无交期数据），仅执行可用的分析模块。
- 供应商评估结果基于当前数据快照，不反映长期趋势。

## 接口约定
- 上游：data-inspector 产出的 `extracted_summary.parquet`（需包含供应商字段）
- 下游：`supplier_report.json` 供 supply-demand-matcher、purchase-advisor、supply-chain-orchestrator 消费
